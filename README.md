Features: Network Scanning • Password Analysis • Log Analysis •
Web Security Testing • Security Reports

Tech Stack: Python Linux Networking Cybersecurity

🛡️ AI Hardening Auditor

A security hardening and compliance framework designed to analyze system
configuration findings, prioritize security risks using contextual
information, and support verified remediation.

System Configuration
        ↓
Security Scanner
        ↓
Security Findings
        ↓
Contextual Analysis
        ↓
AI / LLM Reasoning
        ↓
Risk Prioritization
        ↓
Ansible Remediation
        ↓
Health Check
        ↓
Re-Audit
        ↓
Verification / Rollback

Technologies: Python Wazuh OpenSCAP Ansible LLM Linux

🧠 SIEM Rule Verification using Z3

A security-rule verification pipeline that transforms security requirements
into formal representations and verifies them using the Z3 SMT solver.

Natural Language Security Requirement
                 ↓
             NLP Layer
                 ↓
        Security Rule Model
                 ↓
              HDSL
                 ↓
            BNF Parser
                 ↓
             SMT-LIB
                 ↓
            Z3 Solver
                 ↓
           SAT / UNSAT
                 ↓
        SIEM Rule Processing
                 ↓
         MITRE ATT&CK Mapping

Technologies: Python NLP HDSL BNF SMT-LIB Z3 SIEM
